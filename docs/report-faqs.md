# Report FAQs

The four legacy hardcoded report FAQs are replaced across existing and new report detail pages by the five-question editorial template (size/growth, drivers/trends, segments, regions, companies).

## Automatic answers

`ReportFaqs` extracts plain sentences and structured lists from the saved report summary and segment/company data. It makes no network calls and uses no paid service. Market-size facts require an actual currency value and market context; XX placeholders and company valuations do not qualify. Trends and regional findings require explicit statements in the report. Segmentation follows the actual report headings/lists, with key-info fallback. Companies come from the profiled-companies list or key info; selection criteria and numerical rankings are not invented.

Unsupported answers remain blank in the editor and are omitted from public pages and FAQ structured data. The report's own years, units and geographic scope are retained. Nothing is inferred from the current date or the generic graphic period. Extraction is conservative and should be reviewed for editorial accuracy; it does not independently verify source research.

## Editing

On Add/Edit Report, use **Report FAQs** below Report content:

- **Automatic**: derive supported answers from current saved report content on each view. No per-report row is required.
- **Custom**: publish saved question/answer rows, in the chosen order. Manual answers are not overwritten by subsequent content edits or CSV imports.
- **Hide**: suppress FAQs and FAQ schema while retaining the saved drafts.

Edit a row to switch to Custom. Add, remove and reorder up to 20 rows. **Extract new drafts** uses the unsaved content currently in TinyMCE and current segment fields; it replaces the form's drafts and does not write anything until Save changes. Blank answers never appear publicly. Returning to Automatic removes the custom override.

Public HTML and AMP use the same resolved rows. Answers are escaped plain text with line breaks. A single FAQPage JSON-LD block is generated from exactly those published rows, with script-safe encoding. No FAQ section or schema is emitted for hidden/empty rows. This does not promise search-result eligibility or rankings.

## Storage and deployment

`lr_report_faqs` stores one optional mode/JSON override per report, keyed by report ID. Saves occur in the report-save transaction, and report deletion removes the override. Existing report content is not bulk rewritten. The table was created directly on the live server database before deploying the feature, as requested. Migration `2026_11_01_000002_add_report_faq_overrides` and `database/project-db-update.sql` contain the same structure.

Coverage: SQLite-isolated extraction, missing-data handling, standard/AMP output, editor integration, custom/hidden/auto modes, partial-write validation, HTML/JSON escaping, unsaved extraction and write permissions. No live enquiries or emails are generated by these checks.
